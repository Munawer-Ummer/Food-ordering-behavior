# 🍽️ Food Ordering Behavior Dashboard

An interactive Excel dashboard that analyzes customer ordering behavior on a food delivery platform. It uses 50,000 orders across six Indian cities to show revenue trends, cuisine preferences, ratings, and ordering patterns by time of day, meal type, and day type.

## 📊 Key Metrics

| Metric | Value |
|---|---|
| Total Orders | 50,000 |
| Total Revenue | ₹27,386,555 |
| Average Rating | 2.99 |
| Average Delivery Fee | 59.64 |

City · Cuisine · Day Type · Meal Type · Order Time · Rating Given

## 💡 Key Insights

- **Mumbai** generates the highest revenue (~₹4.64M), followed closely by **Pune** (~₹4.62M).
- **Evening** is the busiest time of day (12,550 orders), though all four time slots are fairly evenly split.
- Cuisine popularity is nearly uniform (~16–17% each), so no single cuisine dominates.
- Average ratings are close to 3.0 across all cuisines. **South Indian** rates highest and **Biryani** lowest.
- **Breakfast** brings in the most revenue among meal types, and **Dinner** the least.
- Weekday and weekend revenue are almost equal (~13.7M each), so weekends show much higher revenue per day.
